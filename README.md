# JatraPath 🌍

### See the World, We’ll Handle the Rest.

JatraPath is a **Smart Tourism Management System** developed as a university project for the **Software Engineering and System Analysis Lab** course.

- **Academic Year:** 2nd Year, 2nd Semester
- **Semester:** Autumn 2026
- **University:** University of Information Technology and Sciences
- **Team:** Binary Explorers

## 🌍 About the Project

JatraPath is a web-based tourism platform that helps users explore destinations and plan their trips from one place.

## ✨ Main Features

- Explore travel destinations.
- View destination details.
- Discover popular tourist spots and hidden gems.
- Search for destinations.
- View travel safety information.
- User registration and login.
- User dashboard.
- Hotel and transportation booking concept.
- Travel budget calculator.
- Gift card management.
- Currency converter.
- Admin dashboard.
- Responsive design for desktop and mobile devices.

## 🚀 Project Status

JatraPath is an ongoing project and is **continuously being updated and improved** with new features, bug fixes, design improvements, and better functionality.
