# JatraPath 🌍

### JatraPath V0.1 — Spring 2025

[JatraPath | V0.1](https://badhonkumarroy.github.io/JatraPath_Website/JatraPath_V0.1/old.html)

JatraPath V0.1 is a tourism website focused on exploring the beauty of Bangladesh. It helps users discover destinations, explore travel packages, plan journeys, and access useful travel information.

## ✨ Main Features

- Explore beautiful destinations of Bangladesh.
- Discover travel packages.
- View tourism and travel information.
- Search for destinations.
- Book travel packages.
- User login page.
- Services section.
- Review section.
- Sponsor section.
- Responsive and user-friendly website design.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
